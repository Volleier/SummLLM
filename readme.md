# SummLLM

## Core Aim
Design and Implementation of a LLM-based model for text summarization
Text summarization is a crucial component of natural language processing (NLP), which helps to translate large amounts of textual data into clear and understandable representations. Text summarization is a widely adopted application for LLM based models. In this project, the student is required to investigate the research literature related to the text summarization task, read the source codes of some LLM-based methods for text summarization. The student needs to select a model as the basis to implement and is required to develop a prototype software system that takes the text as input and outputs the summary.
